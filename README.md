# Personal Expense Tracker

A modern React application for tracking daily expenses.

## Features

- Add Expense
- Edit Expense
- Delete Expense
- Search Expense
- Category Filter
- Pie Chart Summary
- Local Storage
- Responsive Design
- Statistics Dashboard

## Tech Stack

- React
- Vite
- Tailwind CSS
- Chart.js
- React Icons

## Installation

```bash
npm install
```

Run Project

```bash
npm run dev
```

Build Project

```bash
npm run build
```
